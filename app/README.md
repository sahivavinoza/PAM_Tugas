# Tugas 3 - My Profile App (Jetpack Compose)

Aplikasi profil pribadi sederhana yang dibangun menggunakan **Android Studio** dan **Jetpack Compose** dengan menerapkan prinsip *Reusable Composable Functions* dan estetika desain modern bernuansa *earthy* (gaya Hirono).

## 📱 Fitur Aplikasi
- **Header Profil:** Menampilkan foto profil berbentuk lingkaran (*circular*), nama lengkap, program studi/institusi, dan bio singkat.
- **List Informasi Kontak:** Memuat informasi Email kampus, Nomor Telepon, dan Lokasi domisili.
- **Komponen Reusable:** Terdiri dari 3 fungsi komposable utama (`ProfileHeader`, `InfoItem`, dan `ProfileCard`).
- **Desain UI/UX:** Menerapkan palet warna *earthy* yang hangat dengan tata letak kartu yang bersih (*rounded cards*).

## 🛠️ Komponen Jetpack Compose yang Digunakan
- `Column`, `Row`, `Box`
- `Card`, `Surface`
- `Text`, `Button`, `Icon`
- `Modifier` (Padding, Size, Clip, Background, Border, VerticalScroll)
